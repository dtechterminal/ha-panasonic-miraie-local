# Brand images

The integration bundles the unchanged Panasonic icon and logo, in normal and high-resolution variants, from the [Home Assistant brands project](https://github.com/home-assistant/brands/tree/master/core_brands/panasonic).

The Panasonic name and logo belong to Panasonic. They identify the compatible product; this community integration is independent of Panasonic. Brand artwork is not covered by this project's MIT code license.

Home Assistant 2026.3 and newer serves these images directly from the integration's `brand/` folder. See the [Home Assistant announcement](https://contributors.home-assistant.io/blog/2026/02/24/brands-proxy-api/).
